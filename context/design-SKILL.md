# AutoOpt design rules

Settled over many review rounds. Do not re-litigate these; build on them. When in doubt, run `/hallmark audit` and `node web/scripts/shoot.mjs <route>`.

## Direction
- Quirky and technical, dark. Not a Vercel clone: no flat zinc-on-black, no single neutral sans for everything, no centred hero with a gradient blob, no rows of three equal cards, no invented numbers.
- The landing page (`.landing` scope in globals.css) is dark regardless of system theme. Workspace pages still follow the system theme.
- Evidence over decoration: every chart or figure is real engine output generated by a script (`scripts/record_*.py`), never typed in.

## Colour
- Tokens live in `web/app/globals.css` under `.landing`. Use them, never raw hex in components.
- Ramp violet `#8b5cf6` -> blue -> cyan -> green `#3ef2a0`. It encodes rank (worse -> better), not decoration. Shared helpers in `web/components/landing/ramp.ts`.
- Accent green = kept / improved. Refused red `#ff6584` = rejected / no improvement. Same meaning everywhere; don't introduce a second colour language.

## Type
- Syne (`font-hero`) for headlines and primary CTA, bold, tight tracking, fluid `clamp()` sizes. Chakra Petch (`font-display`) for UI text. Azeret Mono (`font-terminal`) for data, code, labels.
- Body copy ~16px, line-height 1.7+. Captions and legends no smaller than ~12.5px.
- Generous vertical rhythm: sections `py-24`, hero `lg:py-32`.

## Surfaces
- Raised surfaces (header, panels, stat tiles) use `<Glass>` from `web/components/landing/glass.tsx`: edge-refraction SVG filter with frosted fallback. The header is a floating rounded pane, not a full-width band (a square pane has no edge to refract).
- Glass CSS lives in `@layer components` so Tailwind utilities (e.g. `sticky`) still override it.
- Backdrop (`backdrop.tsx`): slow drifting washes (periods 34/44/61/96/26s, never sharing a factor), creeping grid, grain tile. Nothing above ~6% opacity.

## Motion
- Nothing pops or jitters. Reveal with masks, springs or opacity/transform; never insert elements abruptly.
- Hover text effects: pure CSS transitions with per-letter `transition-delay` (see `kinetic-heading.tsx`). Split by word first, then letters, and put spaces between word wrappers, never inside them.
- Canvas charts: paint one frame synchronously on mount/resize, then animate only while on screen (IntersectionObserver) and not when the tab is hidden. Avoid per-frame `shadowBlur`; fake glow with wider translucent strokes.
- Pointer parallax moves the whole scene, never the spacing inside it (hover targets must stay put). Tilt direction follows the pointer as if the viewer stepped that way.
- Everything respects `prefers-reduced-motion`.
- Lenis owns scroll; inner scrollers carry `data-lenis-prevent` and `overscroll-contain`. Section reveals use viewport observers (`reveal.tsx`), not ScrollTrigger.

## Layout checks before calling UI done
- No horizontal overflow at 390px and 1440px. Grid children get `min-w-0`.
- Two-column sections balanced in height; use `items-start` plus moving secondary content below, not stretched panels.
- Run `node web/scripts/shoot.mjs <route>`, read both PNGs, fix what you see.
